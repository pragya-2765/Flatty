# 🌟 Flatty — Modern Landing Page Template

Flatty is a clean and stylish **HTML + CSS landing page template** designed for portfolios, startups, personal branding, product showcases, and landing pages.  
It is lightweight, fast, and fully customizable — perfect when you want a quick and elegant web presence 🚀.
